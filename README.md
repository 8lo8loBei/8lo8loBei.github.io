# Beier Xiao's personal homepage

The [website](https://8lo8lobei.github.io/) is served by GitHub Pages from the root of the `main` branch. Committing changes to `main` publishes them automatically.

- `index.html` contains the page text, links, and sections.
- `styles.css` controls the layout, colors, and typography.
- `script.js` handles the gallery, paper figure previews, and illustrations.
- `assets/` contains the gallery photos, illustrations, paper figures, and local fonts.

To preview locally, run `python3 -m http.server 8000` at the repository root and open `http://localhost:8000/`.
